# 篮球零基础到进阶路线图

!!! abstract "使用方法"
    这套笔记按“动作质量 → 速度 → 变化 → 对抗 → 实战选择”推进。先看本页，再进入每个专项。每次只挑 2～4 个重点，不要把所有动作一次练完。

## 训练总原则

1. **先能控制，再追求花哨**：能抬头、能换速、能护球、能在防守前作出选择，才叫控球。
2. **两侧都练**：弱侧手的训练量可为强侧的 1.5～2 倍，直到成功率接近。
3. **动作必须带脚步**：原地熟悉后尽快加入前后左右移动、急停、启动和身体朝向变化。
4. **技术必须进对抗**：无防守 → 标志物 → 影子防守 → 限制性 1v1 → 自由 1v1/比赛。
5. **用命中数和成功率记录**：投篮记录“进球数/出手数”，运球记录“失误数”，对抗记录“有效突破/回合”。
6. **疼痛不是进步**：尖锐痛、关节痛、麻木、明显肿胀或动作变形时停止训练。

达到以下标准再进阶：

- 左右手低运球各 30 秒，眼睛看前方，失误不超过 1 次。
- 左右手全场推进各 2 趟，能控制速度和停球。
- 左右侧近筐单手投篮各连续命中 5 球。
- 左右侧标准上篮各 10 次至少命中 7 次。
- 防守滑步 3×15 秒，双脚不交叉，躯干不明显起伏。

## 每次训练模板（60～90 分钟）

| 环节 | 时长 | 内容 |
|---|---:|---|
| 动态热身 | 8～12 分钟 | 见 [01-热身、落地与基础球性](01-热身、落地与基础球性.md) |
| 当日主项 A | 15～25 分钟 | 控球/投篮/终结之一 |
| 当日主项 B | 15～25 分钟 | 脚步/防守/身体能力之一 |
| 情景或对抗 | 10～20 分钟 | 限制性 1v1、计分投篮、实战终结 |
| 罚球与冷身 | 5～10 分钟 | 疲劳罚球、慢走、轻度活动 |

!!! tip "最小有效训练"
    时间不足时做 25 分钟：热身 5 分钟 + 主项 15 分钟 + 罚球/记录 5 分钟。规律出现比偶尔练到力竭更重要。

## 动作升级规则

每个动作都按以下五级升级：

1. **无球脚步**：先把重心、蹬地和方向做对。
2. **原地持球**：能连续完成且不看球。
3. **移动完成**：左右方向、不同速度、不同距离。
4. **加入判断信号**：伙伴指方向/报颜色，或随机选择投、突、传。
5. **进入对抗**：有限制的 1v1，再到自由实战。

连续两次训练都能以比赛速度完成、成功率达到约 80%，才升一级；一加速就丢球或脚步散掉，则退一级。

## 器材

- 必需：合适尺寸的篮球、能防滑的球鞋、饮水。
- 推荐：5～8 个标志碟、跳绳、弹力带、手机支架、粉笔/胶带。
- 有伙伴时：护垫或抱枕可做轻度对抗；不要用硬物撞击身体。
