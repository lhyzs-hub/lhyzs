# 变向过人进阶组合与节奏训练

返回：[00-篮球零基础到进阶路线图](00-篮球零基础到进阶路线图.md)　基础：[04-变向过人基础动作训练](04-变向过人基础动作训练.md)

## 进阶的核心

组合技不是把动作越接越长，而是“第一招迫使防守移动，第二招惩罚他的反应”。通常两招足够；若三次变向仍没形成优势，优先回撤、传球或重新组织。

## 节奏动作库

### 犹豫步（hesitation）

- 推进中略微抬高身体、球与脚步短暂停顿，眼睛看筐制造投篮/减速信号。
- 防守起身或停脚时立刻压低重心爆发；手必须留在球上方，不能托球。

### 拖曳步（drag/hip swivel）

- 一脚在前减速，后脚拖近，髋部可以打开再关闭。
- 读取防守：后退则投；停住则加速；横移堵路则反向变向。

### 碎步/迟疑启动（stutter）

- 小步快速扰乱时间点，球保持可投可突位置。
- 只在接近防守时使用，随后必须出现明显加速。

### 摇摆步（rocker step）

- 先向前给突破威胁，再把重心收回像要投篮，最后二次向前。
- 三次重心变化要小而快，轴心脚与走步规则要清楚。

### Snatch back / 后拉回撤

- 突破步强烈向前，前脚刹车，把球快速拉回身体后侧。
- 可衔接急停投篮、交叉再突或横撤；落地先稳定再出手。

## 经典组合

### AI 大幅体前

悬浮/停顿 → 肩髋向一侧压 → 大幅体前换手 → 交叉步爆发。先让防守相信第一方向，幅度才有意义。

### Hardaway UTEP Two-step

胯下到一侧 → 立刻体前回到另一侧。第一下保护并引导防守，第二下利用其横移惯性。左右各练，出点后只运 1～2 下。

### Shamgod

同侧手把球向前/外侧推出，另一只手从防守触球前横拉回来。必须先练落点和距离；比赛中空间不足或防守很近时风险高。

### 内外运 → 体前

内外运诱导防守守同侧 → 防守横移后体前反切。若防守没有反应，直接同侧突破，不要强行接第二招。

### 胯下 → 背后

胯下试探一个方向 → 防守压住后用背后保护换向。适合贴身压力，第二下身体要进入球与人之间。

### 体前 → 转身 / 半转身反制

体前后路线仍被堵 → 用背部保护进入转身；若防守提前绕到出口，半转身拉回原方向。

### 回撤 → 再攻击

突破被封 → 回撤拉开 → 防守追上时体前/胯下反向；防守退守时直接投篮或传球。

### 炸球 → 转身/半转身

重运球配合强侧脚落地，身体快速进入背身保护位，再完成转身；半转身是假转后回原方向。

## 随机阅读训练

伙伴扮演 50% 速度防守者，只给三种信号：

- **后退**：急停投篮。
- **堵强侧**：反向变向。
- **贴近伸手**：胯下/背后护球后加速。

每组 8 回合，共 3 组。动作选择正确得 1 分，是否进球另计；先训练决策，再训练命中。

## “一招一反制”训练

选择你最稳定的主招，再配一个反制：

- 主招：内外运同侧突破；反制：内外运接体前。
- 主招：胯下向右；反制：胯下接背后回左。
- 主招：犹豫加速；反制：犹豫急停投篮。
- 主招：回撤投篮；反制：回撤接交叉再突。

每个方向主招进 5 球、反制进 5 球，再做 3 运球 1v1 验证。

## 违例与安全

- 停顿运球时手不能转到球底；合球后不能再次运球。
- 后撤、横撤和收球脚步必须先慢速录像检查，不能以“动作名字”替代规则判断。
- 大幅横移前确认场地无他人、无湿滑区域；对抗时不用手肘清路。

## 进阶标准

- 有一个左右都能做的主招和至少一个反制。
- 限制 3 次运球的 1v1 中，10 回合至少 6 次获得有效出手或篮下优势。
- 能复盘失败原因是距离、时间点、方向还是动作质量，而不是简单归为“速度不够”。
