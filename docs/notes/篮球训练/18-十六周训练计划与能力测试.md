# 十六周训练计划与能力测试

返回：[00-篮球零基础到进阶路线图](00-篮球零基础到进阶路线图.md)

## 默认周结构

| 日程 | 内容 |
|---|---|
| 周一 | 控球 + 上篮 + 力量 A |
| 周二 | 投篮基础 + 防守脚步 |
| 周三 | 休息或轻松活动 |
| 周四 | 变向/三威胁 + 弹跳 |
| 周五 | 接球/运球投篮 + 力量 B |
| 周六 | 对抗 1v1/2v2/3v3 + 罚球 |
| 周日 | 休息、轻松投篮或复盘 |

每周只有 3 天时，选周一、周四、周六，并把防守脚步分散到热身后。未成年人、久坐者或刚恢复运动者从每周 3 次开始。

## 第 0 周：建立基线

只测试，不为成绩透支：

- 左右手低运球 30 秒失误数。
- 左右手全场推进各 2 趟的时间与失误。
- 左右侧标准上篮各 10 次命中数。
- 五点近投 50 球、罚球 20 球命中数。
- 防守滑步 4×15 秒的动作质量。
- 原地纵跳和助跑摸高（可安全测试时）。
- 3 运球 1v1 共 10 回合的合理出手/失误。

## 第 1～4 周：零基础与动作质量

### 主项

- [01-热身、落地与基础球性](01-热身、落地与基础球性.md) 每次训练必做。
- [02-原地运球训练](02-原地运球训练.md) 每周 3 次，每次 10～15 分钟。
- [07-投篮基础与姿势训练](07-投篮基础与姿势训练.md) 每周 2～3 次，以近筐进球数为主。
- [10-上篮与篮下终结训练](10-上篮与篮下终结训练.md) 先左右标准上篮与 Mikan。
- [14-防守姿势、脚步与实战训练](14-防守姿势、脚步与实战训练.md) 只练姿势、滑步、转髋和减速。

### 周末检查

- 第 2 周：弱手低运球 30 秒、左侧上篮 10 球。
- 第 4 周：复测第 0 周项目；动作不稳定的项目继续停留。

## 第 5～8 周：移动、脚步与弱侧

### 主项

- [03-行进间运球、护球与弱手](03-行进间运球、护球与弱手.md)：推进、回撤、变速。
- [04-变向过人基础动作训练](04-变向过人基础动作训练.md)：体前、胯下、背后、转身。
- [06-三威胁与启动脚步训练](06-三威胁与启动脚步训练.md)：试探、顺步、交叉步、扫球。
- [08-接球投篮与移动投篮训练](08-接球投篮与移动投篮训练.md)：一二步和跳步。
- [16-弹跳与爆发力训练](16-弹跳与爆发力训练.md)：采用第 1～3 周级别的落地与基础弹跳。

### 对抗

每周一次影子防守和 3 次运球 1v1，各 6～10 回合。只允许 50%～70% 强度。

## 第 9～12 周：组合、急停与对抗

### 主项

- [05-变向过人进阶组合与节奏训练](05-变向过人进阶组合与节奏训练.md)：选一个主招 + 一个反制。
- [09-运球急停、撤步与中距离训练](09-运球急停、撤步与中距离训练.md)：左右急停、横撤、后撤。
- [10-上篮与篮下终结训练](10-上篮与篮下终结训练.md)：欧洲步、反篮、内侧手、抛投。
- [13-身体对抗与一对一训练](13-身体对抗与一对一训练.md)：软垫接触、限制性 1v1。
- [12-传球、接球与无球跑动训练](12-传球、接球与无球跑动训练.md)：传切、后门、重定位。

### 训练限制

对抗回合规定“最多两招/三次运球”，迫使动作服务于突破、投篮或传球。

## 第 13～16 周：实战阅读与个人技能包

### 建立个人技能树

- 一个稳定启动：顺步、内外运或犹豫启动。
- 一个换向反制：体前、胯下或背后。
- 一个空间动作：回撤、横撤或急停。
- 两种篮下终结：弱手 + 反篮/抛投/内侧手之一。
- 一个无球得分方式：接球投、后门切或重定位。
- 一个防守优势：压弱侧、closeout 或追防。

### 对抗

每周至少一次 1v1 和一次 2v2/3v3。每局后只记录一个决策问题，下一局立即验证。

## 第 16 周复测

使用与第 0 周相同的场地、距离、球和流程。比较：

- 命中率而不是只看进球总数。
- 弱侧与强侧差距。
- 高速时失误数。
- 1v1 合理出手率、失误率和无效运球次数。
- 弹跳/冲刺成绩与落地质量。

## 训练量调整

- 某动作连续两次训练成功率 ≥80%，加入速度、随机信号或轻对抗。
- 成功率降到约 60% 以下，减少速度/距离/防守强度。
- 关节不适、睡眠不足、动作明显迟缓时，把当日改为轻松技术和投篮，不做最大弹跳或全力对抗。
