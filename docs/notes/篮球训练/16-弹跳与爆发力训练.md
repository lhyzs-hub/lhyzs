# 弹跳与爆发力训练

返回：[00-篮球零基础到进阶路线图](00-篮球零基础到进阶路线图.md)　配套：[17-力量、体能、灵活性与恢复训练](17-力量、体能、灵活性与恢复训练.md)

!!! warning "先决条件"
    能无痛深蹲、弓步、单脚提踵，并能完成 [01-热身、落地与基础球性](01-热身、落地与基础球性.md#_3)。膝踝腰疼痛、近期扭伤或明显落地内扣时，先处理问题，不做高强度跳深、连续台阶跳或疲劳摸高。

## 弹跳来自什么

- **相对力量**：腿、髋和躯干能相对于体重产生足够力量。
- **快速发力**：在短时间内把力量释放出来。
- **弹性与刚度控制**：脚踝—膝—髋快速储存和释放能量。
- **技术**：摆臂、倒数两步、下沉幅度、起跳方向和落地。
- **恢复**：高质量弹跳需要神经与肌肉新鲜，不是每天跳到力竭。

## 起跳技术

### 双脚原地起跳

双脚约肩宽，快速下沉，摆臂向后；髋膝踝同时伸展，摆臂上甩，身体向上而非向前。落地回到稳定姿势。

### 双脚助跑起跳

倒数第二步略长以降低重心，最后一步更快更短，双脚迅速完成制动与转向上。先练 60% 速度，再逐渐加速。

### 单脚助跑起跳

保持较高水平速度，最后几步节奏逐渐加快，起跳腿像弹簧快速接触地面，异侧膝与双臂上摆。左右腿都练，但允许存在自然优势侧。

## 低强度弹性动作

- 跳绳/原地小弹跳。
- Pogo 跳（踝主导小跳）。
- 前后/左右线跳。
- 低幅度滑冰跳并稳定落地。
- 原地纵跳单次落稳。

## 力量动作

- 深蹲或杯式深蹲。
- 分腿蹲、反向弓步。
- 罗马尼亚硬拉/髋铰链。
- 台阶上步。
- 单腿臀桥。
- 直膝与屈膝提踵。
- 抗伸展核心（死虫、平板支撑）。

动作教学与组数见 [17-力量、体能、灵活性与恢复训练](17-力量、体能、灵活性与恢复训练.md)。

## 九周进阶计划（每周 2 次）

两次弹跳课间隔至少约 48 小时；每次跳跃总接地次数保持保守，所有重复都应有质量。

### 第 1～3 周：落地与力量基础

- Pogo 3×15。
- 原地纵跳落稳 4×3。
- 侧向小跳落稳 3×4/侧。
- 助跑起跳技术 4×2（60%～75%）。
- 深蹲、分腿蹲、提踵各 3×8～12。

### 第 4～6 周：快速伸缩与单脚控制

- Pogo 3×20。
- 连续跨步跳 3×5/侧。
- 原地反向跳（CMJ）5×3。
- 低箱跳或目标摸高 4×3；下箱请走下，不反复跳下。
- 单脚小跳落稳 3×3/侧。
- 力量动作逐步加负重，但每组保留 2～3 次余力。

### 第 7～9 周：专项爆发

- 助跑双脚摸高 5×2。
- 助跑单脚摸高 4×2/侧。
- 低幅度连续栏跳/线跳 3×5。
- 滑冰跳接加速 3×3/侧。
- 轻负重跳蹲 4×3（仅在动作熟练且有人指导时）；否则做徒手最大意图纵跳。
- 力量训练维持，不在同一天把腿练到力竭。

## 组间休息与停止标准

- 最大意图跳跃组间休息 60～120 秒；摸高可休息更久。
- 连续两次高度明显下降、落地变响、膝内扣或身体失去控制时结束弹跳部分。
- 弹跳训练放在热身后、体能训练前，不在冲刺跑到力竭后练最大跳。

## 测试方法

1. 固定墙面与同一只手，测站立摸高。
2. 热身后做原地摆臂纵跳 3 次，记录最好摸高。
3. 做助跑单脚/双脚起跳各 3 次，记录最好成绩。
4. 纵跳高度 = 跳起摸高 − 站立摸高。

每 4 周测试一次，尽量在同一时间、同样鞋与场地、非疲劳状态下测。

## 不推荐的做法

- 每天数百次跳跃或每天最大摸高。
- 新手直接高箱跳深，或从很高台阶跳下反弹。
- 为了“燃烧感”缩短休息，导致每次跳得越来越低。
- 穿负重背心做大量落地和长距离跑跳。
- 只练跳、不练力量、落地和脚踝小腿。
