# 电路设计索引

## 学习路径

1. [[面包板笔记]]：供电、接线、传感器与模块调试。
2. [[半小时学完单片机基础]]：GPIO、PWM、ADC、中断和通信。
3. [[步进电机笔记]]：STEP/DIR 驱动与运动控制。
4. [[PID控制笔记]]：反馈控制与直流电机速度环。

## 上电前检查

- [ ] 每个器件的工作电压正确。
- [ ] 电源最大电流足够。
- [ ] 3.3 V 与 5 V 信号电平兼容。
- [ ] 所有通信模块共地。
- [ ] 电机、舵机等大电流负载独立供电。
- [ ] 电感负载配置续流或驱动保护。
- [ ] 电源入口和芯片附近配置合适的滤波/去耦。
- [ ] 首次上电设置限流并监测温度。
