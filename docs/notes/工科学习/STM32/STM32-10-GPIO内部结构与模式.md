# STM32 GPIO 内部结构与模式

> [STM32-09-内部结构与总线架构](STM32-09-内部结构与总线架构.md) · [STM32-02-GPIO与外部中断](STM32-02-GPIO与外部中断.md) · [STM32-11-输入输出方式总览](STM32-11-输入输出方式总览.md)

## 一、一个 GPIO 引脚里面有什么

![stm32-gpio-internal-structure](../adobe%20illustrator/attachments/diagrams/stm32-gpio-internal-structure.svg)

!!! tip "看图顺序"
    从右侧外部引脚出发：向下是输入/ADC 路径，向左是输出驱动路径。推挽和开漏的本质区别，是输出驱动级中的上管是否参与工作。

引脚既有输入路径，也可能有输出驱动和模拟连接。模式配置决定哪些路径开启、信号由谁控制。

### F1 GPIO 关键寄存器

| 寄存器 | 作用 | 使用要点 |
|---|---|---|
| `GPIOx_CRL` | 配置引脚 0–7 | 每个引脚由 `MODE[1:0] + CNF[1:0]` 四位配置 |
| `GPIOx_CRH` | 配置引脚 8–15 | 与 CRL 相同，只是负责高八位引脚 |
| `GPIOx_IDR` | 输入数据寄存器 | 读取引脚 PAD 上经过数字输入缓冲后的实际电平 |
| `GPIOx_ODR` | 输出数据寄存器 | 保存希望输出的状态；上拉/下拉输入模式也用对应 ODR 位选择方向 |
| `GPIOx_BSRR` | 原子置位/复位 | 一次写操作只改变目标引脚，避免 ODR 读改写竞态 |
| `GPIOx_BRR` | 复位输出位 | 写 1 清对应 ODR 位 |
| `GPIOx_LCKR` | 锁定配置 | 锁定后通常要到下次复位才能重新配置 |

### MODE 与 CNF 如何选模式

| MODE | CNF | F1 引脚模式 |
|---|---|---|
| `00` | `00` | 模拟输入 |
| `00` | `01` | 浮空输入 |
| `00` | `10` | 上拉/下拉输入；由 ODR 对应位选择上拉还是下拉 |
| 非 `00` | `00` | 通用推挽输出 |
| 非 `00` | `01` | 通用开漏输出 |
| 非 `00` | `10` | 复用推挽输出 |
| 非 `00` | `11` | 复用开漏输出 |

输出模式中 `MODE` 的非零取值还决定 2/10/50 MHz 输出速度等级。CubeMX 会生成这些寄存器配置，理解表格主要用于看手册和调试寄存器。

## 二、数字输入模式

![stm32-gpio-input-circuit](../adobe%20illustrator/attachments/diagrams/stm32-gpio-input-circuit.svg)

这张电路图同时画出了数字与模拟两条输入路径：普通 GPIO、EXTI 和外设复用输入经过施密特触发缓冲；ADC 则从 PAD 进入模拟采样路径。Analog 模式会关闭数字输入缓冲，以减少漏电和数字噪声。

| CubeMX 模式 | 内部状态 | 适合场景 | 风险 |
|---|---|---|---|
| Floating Input | 无内部上下拉 | 外部电路已可靠驱动 | 悬空会随机跳变 |
| Pull-up Input | 弱上拉到 VDD | 按键接地、开漏信号 | 上拉较弱，不适合大电流 |
| Pull-down Input | 弱下拉到 GND | 按键接 VDD、默认低 | 同上 |
| Analog | 关闭数字输入缓冲 | ADC、低功耗未用脚 | 不能当普通数字输入 |

### 浮空为什么随机

CMOS 输入阻抗很高，悬空引脚会被环境电场、走线耦合和手触影响。它不是稳定的 0，也不是稳定的 1。

### 上拉/下拉不是供电

内部上下拉通常是几十 kΩ 量级的弱电阻，只负责确定默认逻辑状态，不能给 LED、模块或负载供电。

### 输入阈值

不要简单认为“大于 1.65 V 就是 1”。高/低电平保证阈值由数据手册给出，并随引脚类型和供电变化。处在中间区间的电平是不确定的。

## 三、数字输出模式

![stm32-gpio-output-drivers](../adobe%20illustrator/attachments/diagrams/stm32-gpio-output-drivers.svg)

左半部分是推挽上下管结构，右半部分是开漏与外部上拉组成的共享总线。I²C 能让多个设备共用 SDA/SCL，正是因为任何设备都只能拉低或释放，不会主动把总线推高。

### 推挽输出 Push-Pull

内部上管可主动拉高，下管可主动拉低：

```text
输出1：引脚被强驱动到高电平
输出0：引脚被强驱动到低电平
```

优点：上升下降快、无需外部上拉。适合 LED、片选、普通控制信号和 UART TX。

推挽状态可理解为：

| ODR/外设输出 | 上管 | 下管 | PAD 状态 |
|---:|---|---|---|
| 1 | 导通 | 关闭 | 主动拉高 |
| 0 | 关闭 | 导通 | 主动拉低 |

### 开漏输出 Open-Drain

只有下管：输出 0 时主动拉低；输出 1 时进入高阻态，需要内部或外部上拉才能得到高电平。

```text
写0 → 拉低
写1 → 释放总线，不等于主动输出高电平
```

适合 I²C、多设备共享中断线、电平转换和“线与”逻辑。I²C 通常需要外部上拉，以满足速率和电容要求。

开漏状态可理解为：

| ODR/外设输出 | 下管 | PAD 状态 |
|---:|---|---|
| 0 | 导通 | 主动拉低 |
| 1 | 关闭 | 高阻态，由上拉或其他器件决定 |

| 对比 | 推挽 | 开漏 |
|---|---|---|
| 主动输出高 | 可以 | 不可以 |
| 主动输出低 | 可以 | 可以 |
| 是否需要上拉 | 通常不需要 | 需要 |
| 多器件共线 | 易冲突 | 可实现线与 |

## 四、普通输出与复用输出

![stm32-gpio-register-mux](../adobe%20illustrator/attachments/diagrams/stm32-gpio-register-mux.svg)

该图把软件寄存器、复用器、输出驱动和输入回读放在同一条路径上：`CRL/CRH` 决定信号从 ODR 还是外设而来，`BSRR/BRR` 修改 ODR，而 `IDR` 从 PAD 的实际电平回读。

- **GPIO Output**：输出值由 ODR/BSRR 控制，使用 `HAL_GPIO_WritePin()`。
- **Alternate Function**：输出由 TIM、USART、SPI 等外设控制，例如 PWM、UART TX、SPI SCK。

即使引脚配置为输出，数字输入路径通常仍可通过 `IDR` 读取 PAD 的实际电平；`ODR` 表示“计划输出什么”，`IDR` 更接近“引脚上实际是什么”。在输出短路或负载过重时，两者可能不一致。

复用模式下仍需正确配置输出类型：UART TX、SPI 时钟常为复用推挽；I²C SCL/SDA 常为复用开漏。

!!! note "F1 与新系列差异"
    STM32F1 使用 AFIO 和固定/重映射关系，配置寄存器主要是 CRL/CRH；较新的 STM32 常用每引脚 AFR 选择复用功能。概念相同，寄存器和 CubeMX 选项不同。

## 五、输出速度是什么意思

F103 的 2/10/50 MHz Output Speed 主要限制输出驱动的边沿速度和能力，不是说 GPIO 会自动输出相应频率。

- 低速信号优先选较低速度，可减少 EMI、振铃和功耗。
- SPI、高频 PWM 等再按时序需要提高速度。
- 速度不等于允许无限驱动电流；负载能力看数据手册。

## 六、模拟模式

ADC 引脚应设为 Analog，关闭数字输入缓冲，减少漏电和数字噪声。F103C8 没有通用片上 DAC；想输出“模拟效果”通常使用 PWM+RC 滤波，或外接 DAC。

## 七、BSRR 为什么比直接改 ODR 安全

`ODR` 读改写在中断并发时可能误改其他引脚。`BSRR` 可原子地置位或复位指定引脚，HAL 的 `HAL_GPIO_WritePin()` 会使用适合的原子写法。

```c
HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, GPIO_PIN_SET);
HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, GPIO_PIN_RESET);
```

三个参数分别是：`LED_GPIO_Port` 为端口寄存器地址，`LED_Pin` 为引脚位掩码，第三个参数为要写入的物理高/低电平。该函数无返回值，完整原型和多引脚规则见 [STM32-02-GPIO与外部中断](STM32-02-GPIO与外部中断.md#_4)。

## 八、复位后的默认状态

F103 大多数普通 GPIO 复位后是浮空输入，调试相关引脚和特殊功能引脚存在例外。不要假设上电时输出一定为 0；驱动电机、继电器等应使用外部上下拉确保复位期间处于安全状态。

## 九、电气边界

- STM32F103 工作与 I/O 供电通常为 2.0–3.6 V。
- “5 V tolerant”只适用于数据手册标记为 FT 的数字引脚和规定条件；模拟模式、供电关闭等场景可能不耐受 5 V。
- GPIO 不能直接驱动电机、继电器、大功率 LED 或舵机。
- 输入电压不得超出绝对最大额定值；限流电阻不能解决所有过压问题。

## 十、模式选择表

| 外设/场景 | 推荐 GPIO 模式 |
|---|---|
| LED | 推挽输出 |
| 按键接 GND | 上拉输入，或下降沿 EXTI |
| UART TX/RX | TX 复用推挽；RX 输入/复用输入 |
| I²C SCL/SDA | 复用开漏 + 外部上拉 |
| SPI SCK/MOSI | 复用推挽 |
| SPI MISO | 输入/复用输入 |
| ADC | 模拟输入 |
| PWM | 定时器复用推挽 |
| 未使用引脚 | 模拟模式或确定的上下拉，兼顾功耗与安全 |

## 十一、故障判断

| 现象 | 可能原因 |
|---|---|
| 输入随机变化 | 浮空、地线不共地、线太长 |
| 开漏输出永远不高 | 没有上拉或上拉过弱 |
| PWM 函数调用了但脚不动 | 引脚未设复用、通道或重映射错误 |
| 输出电压偏低 | 负载过重、推挽/开漏选错、供电问题 |
| ADC 噪声大 | 未用模拟模式、源阻抗高、采样时间短、地噪声 |
