# STM32 时钟树与定时器

> 上一篇：[STM32-04-I2C与OLED](STM32-04-I2C与OLED.md) · 下一篇：[STM32-06-PWM与电机控制](STM32-06-PWM与电机控制.md) · 速查：[STM32-HAL函数速查](STM32-HAL函数速查.md)

对应第 15–21 集：时钟树、基本定时、外部计数、从模式、输入捕获、PWM 和编码器。

## 一、先看时钟树

时钟源经过 PLL、AHB、APB 分频后送到 CPU 和外设。程序里的“1 ms”“115200 baud”“1 kHz PWM”都依赖时钟正确。

F103 常见配置：外部 8 MHz HSE → PLL ×9 → SYSCLK 72 MHz。APB1 通常 36 MHz；当 APB 预分频不为 1 时，定时器时钟常为该 APB 时钟的 2 倍。最终以 CubeMX 时钟图和参考手册为准。

## 二、定时器核心公式

```text
计数频率 = TIM_CLK / (PSC + 1)
更新频率 = TIM_CLK / ((PSC + 1) × (ARR + 1))
更新周期 = 1 / 更新频率
```

例：TIM_CLK=72 MHz，PSC=71，ARR=999：计数 1 MHz，每 1000 次更新，即 1 ms。

!!! warning "加一"
    CubeMX 中 Prescaler 和 Counter Period 写的是寄存器值，实际除数/计数次数都要 `+1`。

## 三、基本定时中断

CubeMX：Clock Source=`Internal Clock`，填写 PSC/ARR，NVIC 开启 TIM global interrupt。

```c
HAL_TIM_Base_Start_IT(&htim2);

void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
  if (htim == &htim2) {
    tick_10ms = 1;
  }
}
```

中断只产生节拍，主循环完成任务。计数不需要中断时用 `HAL_TIM_Base_Start()`。

## 四、外部时钟与从模式

- 外部时钟：外部脉冲驱动 CNT，适合计数传感器脉冲。
- Reset/Gated/Trigger 从模式：由触发输入控制计数器清零、门控或启动。
- 使用前画出“哪个引脚 → 哪个 TI/ETR → 哪个触发源 → CNT 如何变化”。

读取计数：

```c
uint32_t count = __HAL_TIM_GET_COUNTER(&htim2);
__HAL_TIM_SET_COUNTER(&htim2, 0);
```

## 五、输入捕获

边沿到来时，硬件把 CNT 快照到 CCR。两次捕获差值可算周期、频率或脉宽。

```c
HAL_TIM_IC_Start_IT(&htim1, TIM_CHANNEL_3);

void HAL_TIM_IC_CaptureCallback(TIM_HandleTypeDef *htim)
{
  if (htim == &htim1 && htim->Channel == HAL_TIM_ACTIVE_CHANNEL_3) {
    capture = HAL_TIM_ReadCapturedValue(htim, TIM_CHANNEL_3);
  }
}
```

回调只有一个参数 `htim`：它是发生捕获事件的定时器句柄地址。多个定时器共用同一个回调时先判断 `htim == &htim1`；再用 `htim->Channel` 判断刚刚触发的活动通道。这里应和 `HAL_TIM_ACTIVE_CHANNEL_3` 比较，而启动与读取函数使用的是 `TIM_CHANNEL_3`，两类常量不要混用。回调无返回值。

HC-SR04：TRIG 输出至少 10 μs 脉冲；ECHO 上升沿记录开始，下降沿记录结束。

```text
distance_cm = pulse_us × 0.034 / 2
```

必须处理计数器溢出与超时，否则“无回波”会卡住流程。

## 六、编码器模式

CubeMX：两个通道设 Encoder Mode，必要时提高 Input Filter。

```c
HAL_TIM_Encoder_Start(&htim1, TIM_CHANNEL_ALL);
int16_t delta = (int16_t)__HAL_TIM_GET_COUNTER(&htim1);
__HAL_TIM_SET_COUNTER(&htim1, 0);
```

把计数解释为 `int16_t`，可自然处理方向与 16 位回绕。机械 EC11 需要滤波；电机编码器还要结合减速比与倍频计算角度/转速。

## 七、定时器函数参数详解

### 1. 启动基本定时器

```c
HAL_StatusTypeDef HAL_TIM_Base_Start(TIM_HandleTypeDef *htim);
HAL_StatusTypeDef HAL_TIM_Base_Start_IT(TIM_HandleTypeDef *htim);
```

| 参数/返回值 | 含义 |
|---|---|
| `htim` | 定时器句柄地址，如 `&htim2`；包含 `TIM2` 实例和 PSC、ARR 等配置 |
| `_Start` | 只启动计数，不开启更新中断回调 |
| `_Start_IT` | 启动计数并允许更新中断，CubeMX 还必须开启对应 NVIC IRQ |
| 返回值 | `HAL_OK` 表示启动成功；`HAL_ERROR` 等表示未成功启动 |

更新事件回调：

```c
void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim);
```

回调参数 `htim` 指向产生更新事件的定时器。多个定时器共用该弱回调时，必须用 `if (htim == &htim2)` 或 `htim->Instance == TIM2` 区分。

### 2. 读写计数器

```c
uint32_t count = __HAL_TIM_GET_COUNTER(&htim2);
__HAL_TIM_SET_COUNTER(&htim2, value);
```

| 参数 | 含义 |
|---|---|
| 第 1 个参数 | 定时器句柄地址，如 `&htim2` |
| `value` | 要写入计数寄存器 CNT 的值，应处于计数器有效位宽和 ARR 范围内 |
| GET 返回值 | 当前 CNT 计数值，类型按宏返回为无符号整数 |

### 3. 输入捕获

```c
HAL_StatusTypeDef HAL_TIM_IC_Start_IT(
    TIM_HandleTypeDef *htim,
    uint32_t Channel);

uint32_t HAL_TIM_ReadCapturedValue(
    const TIM_HandleTypeDef *htim,
    uint32_t Channel);
```

| 参数 | 含义 |
|---|---|
| `htim` | 输入捕获所属的定时器句柄，如 `&htim1` |
| `Channel` | 配置通道常量：`TIM_CHANNEL_1`～`TIM_CHANNEL_4`，不是数字 `1～4` |
| Start 返回值 | 是否成功启动该通道的捕获和中断 |
| Read 返回值 | 对应捕获比较寄存器 CCRx 保存的时间戳 |

回调中的 `htim->Channel` 要与 `HAL_TIM_ACTIVE_CHANNEL_3` 等“活动通道常量”比较；调用启动/读取函数时则传 `TIM_CHANNEL_3`。两组常量名称不同，不能混用。

### 4. 编码器模式

```c
HAL_StatusTypeDef HAL_TIM_Encoder_Start(
    TIM_HandleTypeDef *htim,
    uint32_t Channel);
```

| 参数 | 含义 |
|---|---|
| `htim` | 配置为 Encoder Mode 的定时器句柄 |
| `Channel` | 通常传 `TIM_CHANNEL_ALL`，同时启动编码器使用的通道1和通道2 |
| 返回值 | `HAL_OK` 表示编码接口已经启动 |

## 八、输入输出总结

| 模式 | 输入 | 输出 |
|---|---|---|
| 基本定时 | 内部时钟 | 周期事件/中断 |
| 外部计数 | 外部脉冲 | CNT 计数 |
| 输入捕获 | 外部边沿 | CCR 时间戳 |
| 编码器 | A/B 两相信号 | 有方向的位置计数 |
| PWM | 定时器时钟、CCR | 周期方波 |
