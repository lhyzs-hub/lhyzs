# 机械任务与项目推进笔记

!!! abstract "用法"
    把模糊的机械任务拆成“需求—方案—设计—制造—装配—验证”六个阶段，每个阶段都有可交付结果。

## 项目流程

```mermaid
flowchart LR
    A["明确需求"] --> B["方案比较"]
    B --> C["详细设计"]
    C --> D["加工采购"]
    D --> E["装配调试"]
    E --> F["验证复盘"]
```

## 1. 明确需求

- 功能：机构必须完成什么动作？
- 负载：质量、力、力矩和冲击是多少？
- 行程：直线距离或旋转角度是多少？
- 速度与精度：允许误差和重复定位精度是多少？
- 空间：外形、安装孔位、运动包络和线缆空间。
- 环境：温度、粉尘、水汽、振动和维护条件。
- 约束：预算、加工能力、标准件和交付时间。

优先使用成熟标准件，避免为了“看起来高级”增加不必要的零件与装配公差。

## 3. 详细设计检查

- [ ] 完成受力路径和危险截面判断。
- [ ] 校核电机转矩、减速比和安全系数。
- [ ] 检查轴承、联轴器、丝杆或同步带选型。
- [ ] 预留装配、工具和维护空间。
- [ ] 明确基准、关键尺寸、公差和表面处理。
- [ ] 检查紧固件长度、干涉和防松。
- [ ] 线缆不会在全行程中拉扯或夹伤。
- [ ] 输出 BOM 和二维工程图。

## 4. 常用工具

- CAD：SolidWorks、AutoCAD、CATIA。
- 仿真：ANSYS、MATLAB/Simulink。
- 制造：3D 打印、激光切割、CNC、车铣加工。
- 测量：游标卡尺、千分尺、百分表、扭力工具。
