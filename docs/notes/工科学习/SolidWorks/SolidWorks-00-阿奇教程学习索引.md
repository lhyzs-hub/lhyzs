# SolidWorks 阿奇教程学习索引

>  [机械任务笔记](../koala考核期/机械任务笔记.md)

> [!summary] 目标
> 从零完成“参数化零件 → 装配体 → 工程图 → 打包/导出”的完整工作流，并能独立排查草图、特征和配合错误。

## 教程依据

主教程：[阿奇设计分享《SOLIDWORKS 教学 精品教程》BV1iw411Z7HZ](https://www.bilibili.com/video/BV1iw411Z7HZ)。教程共 43 个分段，覆盖草图、特征、放样、钣金、装配体、桌下抽屉实战、工程图和小风扇底座实战，适用于 2012—2024 的主要版本。不同版本的图标位置可能变化，但建模逻辑基本一致。

## 推荐学习顺序

```mermaid
flowchart LR
    A["界面与视图"] --> B["草图完全定义"]
    B --> C["零件特征"]
    C --> D["装配体配合"]
    D --> E["工程图"]
    E --> F["综合项目"]
    F --> G["复盘与提速"]
```

| 阶段 | 对应视频 | 学习产物 | 验收标准 |
|---|---|---|---|
| 基础 | P1～P2 | 自定义模板、视图操作 | 能不看菜单完成保存、旋转、缩放、正视 |
| 草图 | P3～P8 | 3 张完全定义草图 | 线条由蓝变黑，修改尺寸后形状稳定 |
| 特征 | P9～P20 | 手机支架或自选零件 | 设计树清楚，无红叉黄警告 |
| 装配 | P21～P25 | 轴孔或滑块装配 | 只保留预期自由度，无重复配合 |
| 综合 | P26～P32 | 桌下抽屉 | 零件、装配、打印件能统一修改 |
| 工程图 | P33～P34 | A4 零件工程图 | 视图足够、尺寸可制造、单位正确 |
| 项目 | P36～P43 | 小风扇摇头底座 | 能解释每个特征和每个配合的目的 |

## 正确练习方法

每一课按“四遍法”练习：

1. 第一遍只观看，理解目标和命令选择。
2. 第二遍暂停跟做，命名草图和特征。
3. 第三遍关掉视频，仅看最终尺寸独立重画。
4. 第四遍修改 2～3 个关键尺寸，检查模型是否仍然稳定。

> [!tip] 不要把“画出来”当成学会
> 真正掌握的标准是：尺寸变化后模型不崩、设计树能读懂、装配运动正确、工程图可以交给别人制造。

## 统一命名建议

- 文件：`项目-零件名-版本.SLDPRT`，例如 `抽屉-左导轨-V01.SLDPRT`。
- 草图：`SK_用途`，例如 `SK_底座外形`。
- 特征：`EX_主体`、`CUT_安装孔`、`FIL_外观圆角`。
- 装配体：`项目总装.SLDASM`。
- 工程图：与零件或装配体同名，扩展名 `.SLDDRW`。
