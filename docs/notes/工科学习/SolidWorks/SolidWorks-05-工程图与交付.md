# SolidWorks 05 工程图与交付

> 上一篇：[[SolidWorks-04-装配体与配合]] · [[SolidWorks-00-阿奇教程学习索引]] · 下一篇：[[SolidWorks-06-综合实战与排错]]

对应教程：P33“工程图1”、P34“工程图2”，以及版本问题、打包和 3D 打印相关附加课。

## 一、工程图不是模型截图

工程图的目的，是让制造、检验和装配人员在不打开三维模型的情况下理解：形状、尺寸、公差、材料、表面要求、数量和版本。

一张合格工程图至少要做到：视图表达充分、尺寸不重不漏、技术要求明确、比例和单位正确。

## 二、从模型创建工程图

1. 打开零件或装配体。
2. `文件 → 从零件/装配体制作工程图`。
3. 选择 A4/A3 模板和第一/第三视角标准。
4. 从“视图调色板”拖入主视图。
5. 用投影视图生成俯视、左/右视和等轴测。
6. 设置显示样式、比例和切线边。

主视图应最清楚地表达零件主要形状和加工位置，而不是机械地选择模型的“前视”。

## 三、常用视图

| 视图 | 用途 | 注意点 |
|---|---|---|
| 模型视图 | 插入标准方向或保存视图 | 确认方向、比例、显示样式 |
| 投影视图 | 从父视图投影 | 与父视图保持对齐 |
| 剖视图 | 表达内部孔槽 | 剖切线和箭头方向清楚 |
| 局部剖视图 | 只展示局部内部结构 | 标明深度边界 |
| 断裂视图 | 缩短长轴、长杆 | 不可误导长度尺寸 |
| 详图 | 放大局部细节 | 标注区域和比例 |
| 辅助视图 | 正对斜面 | 适合斜孔、斜面真实形状 |
| 爆炸视图 | 表达装配顺序 | 配合 BOM 和零件序号 |

## 四、尺寸与注解

### 模型项目与智能尺寸

- “模型项目”导入模型中已有尺寸，适合模型尺寸规划良好的零件。
- “智能尺寸”在工程图中补充必要尺寸。
- 不能把草图和特征里的所有尺寸无选择地全部导入，否则图面拥挤、重复。

### 基本标注顺序

1. 总体尺寸：长、宽、高。
2. 功能尺寸：孔距、配合直径、安装面距离。
3. 加工尺寸：槽宽、深度、倒角、圆角。
4. 公差、粗糙度、形位要求。
5. 材料、热处理、表面处理和未注要求。

### 孔标注

对孔向导创建的孔使用“孔标注”，可自动读取数量、直径、深度、沉头或螺纹信息。若信息不完整，回到零件检查孔向导定义。

### 中心线与中心符号线

圆孔、回转体和对称结构应添加中心线。中心线用于表达轴线，不应被误作实体轮廓。

## 五、公差的入门理解

- 尺寸公差：限制长度或角度允许变化。
- 配合：孔和轴的公差组合决定间隙、过渡或过盈。
- 形位公差：限制形状、方向和位置误差。
- 基准：测量与几何公差的共同参考。

不要为了“显得专业”随意添加很小公差。公差越严，制造和检验成本通常越高，应由功能、工艺和成本共同决定。

## 六、装配工程图

典型内容：

1. 总装主视、投影视和必要剖视。
2. 爆炸视图。
3. 材料明细表 BOM。
4. 自动零件序号。
5. 外形、安装和接口尺寸。
6. 装配技术要求。

BOM 信息来自零件自定义属性。建议在零件中填写 `Description`、`Material`、`Part Number`、`Revision` 等，而不是在表格里手工覆盖。

## 七、图纸格式与模板

- 图纸格式包含边框、标题栏和固定文字。
- 工程图模板包含单位、制图标准、字体、箭头、图纸格式等设置。
- 编辑标题栏时链接自定义属性，可让名称、材料、质量和图号自动更新。

保存模板前，用一个测试零件验证比例、字体、线宽、投影标准和 PDF 输出。

## 八、版本兼容与中性格式

SOLIDWORKS 原生文件通常不能直接由更老版本打开。跨版本或跨软件协作可导出：

| 格式 | 保留内容 | 适合 |
|---|---|---|
| STEP `.step/.stp` | 精确实体/曲面，通常无特征历史 | 跨 CAD 交换、加工 |
| Parasolid `.x_t` | 高质量几何，SOLIDWORKS 内核兼容好 | CAD 间交换 |
| IGES `.igs` | 曲面为主 | 老系统交换，不优先 |
| STL `.stl` | 三角网格，无参数特征 | 3D 打印 |
| 3MF `.3mf` | 网格及更多打印信息 | 现代 3D 打印工作流 |
| DXF/DWG | 二维几何 | 激光切割、二维图纸 |
| PDF | 只读图纸表达 | 审阅、打印和交付 |

导入中性格式后使用“导入诊断”检查并修复坏面和缝隙。

## 九、3D 打印导出

1. 检查模型是封闭实体，无零厚度和自相交。
2. 确认单位为 mm。
3. `另存为 → STL/3MF → 选项`。
4. 选择合适分辨率；过低会使圆面明显多边形化，过高只会增大文件。
5. 检查坐标方向和打印摆放。
6. 在切片软件中再次确认外形尺寸。

STL 不携带“毫米还是英寸”的可靠语义，导出和切片两端必须核对尺寸。

## 十、Pack and Go

交付装配项目的标准操作：

1. 打开顶层装配体。
2. `文件 → Pack and Go`。
3. 勾选工程图、Toolbox 零件、外观等需要的引用。
4. 选择统一文件夹或 ZIP。
5. 必要时添加前缀/后缀，避免覆盖原项目。
6. 在另一目录解压并打开顶层装配体，验证没有丢失引用。

## 十一、出图检查表

- [ ] 投影法与公司/课程标准一致。
- [ ] 主视图选择合理，视图数量足够但不重复。
- [ ] 比例、单位、材料和版本明确。
- [ ] 尺寸不重、不漏、不封闭成矛盾尺寸链。
- [ ] 孔、螺纹、倒角和圆角表达完整。
- [ ] 公差与功能相符。
- [ ] 标题栏、图号、日期和设计者正确。
- [ ] PDF 打印后文字和线型仍清晰。
- [ ] 装配图 BOM 与零件序号一致。
