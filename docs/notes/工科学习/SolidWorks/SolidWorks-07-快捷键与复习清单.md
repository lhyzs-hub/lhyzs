# SolidWorks 07 快捷键与复习清单

> [SolidWorks-00-阿奇教程学习索引](SolidWorks-00-阿奇教程学习索引.md) · [SolidWorks-06-综合实战与排错](SolidWorks-06-综合实战与排错.md)

!!! warning "快捷键可能被自定义"
    下表是常见默认值与推荐设置。请在 `工具 → 自定义 → 键盘` 中搜索命令，确认当前版本和当前电脑的实际绑定。

## 一、文件与编辑

| 快捷键 | 命令 | 使用建议 |
|---|---|---|
| `Ctrl+N` | 新建 | 选择零件/装配体/工程图模板 |
| `Ctrl+O` | 打开 | 使用最近文档也可快速切换 |
| `Ctrl+S` | 保存 | 完成一个关键特征就保存一次 |
| `Ctrl+Shift+S` | 另存为 | 分版本保存前检查引用关系 |
| `Ctrl+P` | 打印 | 工程图打印前检查比例 |
| `Ctrl+Z` | 撤销 | 不要依赖无限撤销，重要节点另存版本 |
| `Ctrl+Y` | 重做 | 恢复撤销动作 |
| `Ctrl+C/V` | 复制/粘贴 | 草图实体、注解等 |
| `Delete` | 删除 | 删除特征前先查看子特征 |
| `Esc` | 退出命令/清除状态 | 高频使用 |

## 二、视图与显示

| 快捷键/操作 | 功能 |
|---|---|
| 中键拖动 | 旋转模型 |
| 滚轮 | 缩放 |
| `Ctrl`+中键拖动 | 平移 |
| `F` | 整屏显示全部 |
| `G` | 放大镜 |
| `Space` | 视图方向面板 |
| `Ctrl+1` | 前视 |
| `Ctrl+2` | 后视 |
| `Ctrl+3` | 左视 |
| `Ctrl+4` | 右视 |
| `Ctrl+5` | 上视 |
| `Ctrl+6` | 下视 |
| `Ctrl+7` | 等轴测 |
| `Ctrl+8` | 正视于所选面/草图 |
| `Tab` | 隐藏鼠标指向的零部件/实体 |
| `Shift+Tab` | 显示隐藏对象 |

记忆：`1～6` 是六个正交方向，`7` 是等轴测，`8` 是正视当前选择。

## 三、草图与建模

| 快捷键 | 常见默认命令 | 备注 |
|---|---|---|
| `S` | 快捷栏 | 随当前环境显示草图/零件/装配/工程图命令 |
| `L` | 直线 | 连续画线，双击或 `Esc` 结束 |
| `A` | 三点圆弧切换 | 在连续直线绘制时也可切换圆弧 |
| `R` | 矩形 | 某些版本/配置可能不同 |
| `D` | 智能尺寸 | 若未绑定，建议自行设置 |
| `Ctrl+B` | 重建 | 只重建发生变化部分 |
| `Ctrl+Q` | 强制重建 | 完整重建，排错用 |

`S` 快捷栏比死记几十个键更实用：把“草图、智能尺寸、拉伸、切除、圆角、配合、测量”放入相应环境快捷栏。

### 3.1 推荐自定义快捷键

下面不是所有电脑都会自带的默认键，而是一套适合跟随教程和日常建模的推荐配置。设置位置：`工具 → 自定义 → 键盘`，在“搜索”中找到命令，再单击“快捷键”单元格录入组合键。

| 推荐快捷键 | 搜索的命令 | 使用方法 |
|---|---|---|
| `Alt+C` | `构造几何线` / `Construction Geometry` | 绘制前切换为构造线，或选中已有草图实体后在实线与构造线之间切换 |
| `Alt+D` | `智能尺寸` / `Smart Dimension` | 快速进入尺寸标注 |
| `Alt+L` | `中心线` / `Centerline` | 绘制对称轴、旋转轴和尺寸基准 |
| `Alt+E` | `转换实体引用` / `Convert Entities` | 将已有边线或轮廓投影到当前草图 |
| `Alt+O` | `等距实体` / `Offset Entities` | 创建固定距离的平行轮廓 |
| `Alt+T` | `剪裁实体` / `Trim Entities` | 快速进入强力剪裁或剪裁到最近端 |
| `Alt+M` | `镜向实体` / `Mirror Entities` | 关于中心线镜像草图实体 |
| `Alt+B` | `拉伸凸台/基体` / `Extruded Boss/Base` | 将封闭草图拉伸为实体 |
| `Alt+X` | `拉伸切除` / `Extruded Cut` | 使用草图切除材料 |
| `Alt+H` | `孔向导` / `Hole Wizard` | 创建沉头孔、螺纹孔等标准孔 |
| `Alt+F` | `圆角` / `Fillet` | 创建零件圆角；注意可能与软件菜单助记键冲突 |

!!! tip "`Alt+C` 的两种用法"
    - **先按 `Alt+C` 再画线**：新绘制的实体作为构造几何线。
    - **先选中草图实体再按 `Alt+C`**：把已有实线切换为构造线，再按一次可切回普通实线。

设置 `Alt+C`：

1. 打开任意零件并进入草图，确保相关草图命令已加载。
2. 进入 `工具 → 自定义 → 键盘`。
3. 搜索 `构造几何线`；英文界面搜索 `Construction Geometry`。
4. 在快捷键栏按下 `Alt+C`。
5. 如果出现“已分配”提示，先判断原命令是否需要，再选择是否替换。
6. 新建草图，分别测试“空选择时切换绘制模式”和“选中线段后切换类型”。

!!! warning "不要一次设置太多"
    先固定使用 `Alt+C`、`Alt+D`、`Alt+E`、`Alt+O`、`Alt+T` 五个高频键。一周后再加入特征快捷键，避免按键记忆互相干扰。不同版本、语言和菜单助记键可能占用某些 `Alt` 组合，以自定义窗口显示的冲突提示为准。

## 四、选择效率

| 操作 | 功能 |
|---|---|
| `Ctrl+单击` | 多选或取消单个选择 |
| 左→右框选 | 仅选完全位于框内对象 |
| 右→左框选 | 选框内及被交叉对象 |
| 右键 → 选择其他 | 选择被遮挡的面/边 |
| 右键 → 选择相切 | 选择连续相切面/边 |
| 设计树过滤框 | 按名称找草图、特征、配合或零件 |

## 五、鼠标笔势

在图形区按住右键并向某方向拖动，可启动分配的命令。官方帮助说明可为零件、装配体、工程图和草图分别设置 2、3、4、8 或 12 个笔势。

推荐 8 向设置：

| 环境 | 推荐命令 |
|---|---|
| 草图 | 直线、中心线、矩形、圆、智能尺寸、修剪、镜像、退出草图 |
| 零件 | 草图、拉伸凸台、拉伸切除、孔向导、圆角、测量、剖视、正视 |
| 装配体 | 插入零件、配合、移动零件、旋转零件、干涉检查、爆炸视图、测量、剖视 |
| 工程图 | 模型视图、投影视图、剖视图、智能尺寸、孔标注、中心线、注释、BOM |

设置位置：`工具 → 自定义 → 鼠标笔势`。修改后通过 `工具 → 保存/恢复设置` 备份到设置文件。

## 六、命令搜索与自定义

找不到命令时：

1. 使用右上角搜索框切换到“命令”。
2. 输入中文或英文关键词，如“放样/Loft”。
3. 搜索结果可直接运行，有些版本还能拖到工具栏。
4. 在 `工具 → 自定义 → 键盘` 中按“类别”和“搜索”定位命令。

推荐只自定义 10 个真正高频的命令，并把设置导出备份；过多自定义会导致换电脑后难以操作。完成上表设置后，使用 `工具 → 保存/恢复设置 → 保存设置` 导出 `.sldreg`，重装软件或换电脑时即可恢复。

## 七、一分钟工作流速记

```text
新建零件 → 选基准面 → 草图 → Ctrl+8
→ 大致轮廓 → 几何关系 → 智能尺寸 → 完全定义
→ 退出草图 → 拉伸/旋转/扫描/放样
→ 孔槽 → 阵列/镜像 → 圆角倒角
→ Ctrl+Q 检查 → 材料/质量 → 保存
→ 装配配合 → 干涉检查 → 工程图 → Pack and Go
```

## 八、7 天复习安排

| 天数 | 内容 | 必交成果 |
|---|---|---|
| 1 | 界面、视图、文件和模板 | MMGS 零件模板 |
| 2 | 草图实体、关系和尺寸 | 3 张完全定义草图 |
| 3 | 拉伸、旋转、孔、圆角和阵列 | 阶梯轴+法兰 |
| 4 | 扫描、放样、抽壳和设计树 | 支架或外壳 |
| 5 | 装配与标准配合 | 轴承座装配 |
| 6 | 工程图和文件交付 | A4 零件图+STEP |
| 7 | 综合实战与排错 | 手机支架或抽屉项目复画 |

## 九、阶段自测

### 入门通过

- [ ] 能解释零件、装配体和工程图之间的引用关系。
- [ ] 能让草图完全定义，并判断过定义原因。
- [ ] 能独立使用拉伸、旋转、孔向导、圆角、镜像和阵列。
- [ ] 能用同心+重合完成轴孔装配。
- [ ] 能创建主视、投影视、剖视和基本尺寸。

### 实战通过

- [ ] 修改主参数后无重建错误。
- [ ] 装配体只保留预期自由度。
- [ ] 能定位最早红叉并修复丢失引用。
- [ ] 能完成干涉检查、质量检查和工程图检查。
- [ ] 能使用 Pack and Go 交付完整项目。
