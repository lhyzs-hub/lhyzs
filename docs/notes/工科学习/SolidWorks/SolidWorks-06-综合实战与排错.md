# SolidWorks 06 综合实战与排错

> 上一篇：[SolidWorks-05-工程图与交付](SolidWorks-05-工程图与交付.md) · [SolidWorks-00-阿奇教程学习索引](SolidWorks-00-阿奇教程学习索引.md) · 下一篇：[SolidWorks-07-快捷键与复习清单](SolidWorks-07-快捷键与复习清单.md)

对应教程：P16 手机支架、P26～P32 桌下抽屉、P36～P43 小风扇摇头底座。

## 一、接到模型先做功能拆解

不要立即找命令。先写清楚：

1. 哪些是承力或安装基准？
2. 哪些尺寸由外部物体决定？
3. 哪些部分需要运动、装配间隙或紧固件？
4. 零件用什么工艺制造：3D 打印、机加工、钣金还是标准件？
5. 未来最可能修改哪些参数？

把“功能基准”和“可能变化的尺寸”放在模型上游。

## 二、手机支架建模拆解

### 关键输入

- 手机宽度、厚度和壳体余量。
- 支撑倾角。
- 底座长度和防倾倒尺寸。
- 充电口、按键和摄像头避让。
- 3D 打印最小壁厚、圆角和打印方向。

### 推荐设计树

```text
SK_侧面主轮廓
EX_支架主体
SK_手机容纳槽
CUT_容纳槽
SK_充电线避让
CUT_充电线孔
FIL_结构圆角
FIL_触碰圆角
```

### 操作逻辑

1. 在右视基准面绘制侧面主轮廓，用角度和关键高度控制姿态。
2. 中面拉伸得到主体宽度。
3. 在前面切出手机槽，使用“到面”或明确深度。
4. 添加充电线避让孔。
5. 最后添加圆角；与打印平台接触的底面保持稳定。

验收：修改手机厚度和宽度后，槽仍居中、壁厚合理、圆角不失败。

## 三、桌下抽屉项目拆解

### 文件层级

```text
桌下抽屉/
├─ 零件/
│  ├─ 抽屉盒.SLDPRT
│  ├─ 左导轨.SLDPRT
│  ├─ 右导轨.SLDPRT
│  └─ 安装座.SLDPRT
├─ 桌下抽屉总装.SLDASM
├─ 桌下抽屉总装.SLDDRW
└─ 输出/
```

### 参数建议

- 桌板厚度和可用安装宽度。
- 抽屉外宽、深度、高度。
- 单侧滑动间隙。
- 导轨长度、限位位置和螺钉规格。
- 打印件壁厚、孔径补偿和装配方向。

### 建模顺序

1. 先完成抽屉盒主体，外形使用中心矩形和中面拉伸。
2. 生成侧面导向结构和前端把手。
3. 以抽屉外形和间隙为依据建立导轨。
4. 左右导轨若为镜像关系，使用派生/镜像策略，不重复手画。
5. 装配时固定桌板或安装基准件。
6. 用宽度配合或平行+距离使抽屉居中。
7. 用限制距离保留开合行程。
8. 做干涉检查，分别检查关闭和完全拉出位置。

### 需要打印验证的尺寸

- 导轨间隙。
- 螺钉孔实际打印直径。
- 卡扣或限位凸台厚度。
- 抽屉拉出时的重心和抗倾覆。

先打印 30～50 mm 的小截面试件验证间隙，比直接打印完整抽屉更省时间。

## 四、小风扇摇头底座项目拆解

### 功能模块

- 固定底座：承重和安装。
- 旋转轴/轴承位：允许水平转动。
- 摇头连杆或偏心机构：把旋转转为往复摆动。
- 电机安装：定位、电线避让和散热。
- 外壳：保护、外观和装配拆卸。

### 推荐建模策略

1. 先做运动骨架草图，定义旋转中心、摆角、连杆长度和极限位置。
2. 根据骨架确定底座和支架安装基准。
3. 标准件尽量使用简化模型，不建真实螺纹。
4. 装配中用同心、重合、槽口或限制角度保留预期运动。
5. 拖动或运动算例检查整段行程，而不是只看静止位置。
6. 在极限位置运行干涉和间隙检查。

### 运动验证

- 连杆是否经过死点并卡住。
- 电机轴和从动轴是否同轴/平行。
- 外壳是否与摆动零件碰撞。
- 电线是否有足够弯曲和摆动空间。
- 底座重量和支撑范围是否能抵抗风扇惯性。

## 五、通用报错排查

### 草图无法生成特征

1. 使用“检查草图以用于特征”。
2. 放大检查开放端点和重叠线。
3. 检查构造线/实线类型。
4. 检查轮廓是否自交。
5. 用“所选轮廓”逐块测试。

### 特征重建失败

1. `Ctrl+Q` 强制重建。
2. 找设计树中最早的红叉。
3. 检查草图平面或终止面是否丢失。
4. 检查圆角、抽壳、放样是否产生零厚度或自交。
5. 回滚到失败特征之前，逐个取消压缩定位原因。

### 零厚度几何

两个实体只在一条边或一个点接触，无法形成有效实体。让几何体有真实重叠、留出间隙，或保持为独立多实体。

### 圆角失败

- 半径大于附近空间。
- 一次选择太多复杂边。
- 上游小面导致过渡冲突。

处理：减小半径、分批圆角、调整特征顺序，或用面圆角替代边圆角。

### 抽壳失败

把圆角和小细节暂时压缩，先对简单主体抽壳；检查最小曲率和狭窄区域是否小于壁厚。

### 放样/扫描扭曲

- 对齐各截面的连接点。
- 确保引导线与每个截面“穿透”。
- 减少不必要的控制曲线。
- 检查截面顺序和法向方向。

### 装配体零件丢失

使用“查找引用”确认原路径；重新指定文件后立即执行 Pack and Go。不要在资源管理器里随意重命名已被装配体引用的零件。

### 装配体过定义

压缩最近配合，检查固定状态和重复自由度。以“需要保留什么运动”为准重建最少配合。

## 六、模型提交前检查

- [ ] 所有草图按需要完全定义。
- [ ] 设计树无红叉、黄警告和无意义草图。
- [ ] 草图和特征已命名。
- [ ] 关键尺寸改变后模型仍可重建。
- [ ] 材料、质量和单位正确。
- [ ] 装配运动范围正确，极限位置无干涉。
- [ ] 标准件规格和孔向导匹配。
- [ ] 工程图、STEP/STL 和原生文件输出完整。
- [ ] 使用 Pack and Go 在独立目录验证可打开。
