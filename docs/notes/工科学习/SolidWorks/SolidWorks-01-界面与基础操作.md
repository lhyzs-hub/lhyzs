# SolidWorks 01 界面与基础操作

> [SolidWorks-00-阿奇教程学习索引](SolidWorks-00-阿奇教程学习索引.md) · 下一篇：[SolidWorks-02-草图绘制与完全定义](SolidWorks-02-草图绘制与完全定义.md)

对应教程：P1“软件界面及基础操作”、P2“学习地图”。

## 一、先认识三类文件

| 类型 | 扩展名 | 用途 | 关键关系 |
|---|---|---|---|
| 零件 | `.SLDPRT` | 单个可制造物体 | 是装配体和工程图的源模型 |
| 装配体 | `.SLDASM` | 组合零件并定义运动关系 | 引用外部零件文件，不是简单复制 |
| 工程图 | `.SLDDRW` | 二维制造表达 | 引用零件/装配体，模型变化后可更新 |

移动项目时不能只复制 `.SLDASM`，否则装配体会丢失零件引用。交付项目应使用 `文件 → Pack and Go`，详见 [SolidWorks-05-工程图与交付](SolidWorks-05-工程图与交付.md)。

## 二、界面分区

![01-界面分区](../adobe%20illustrator/attachments/SolidWorks/01-界面分区.png)

### 2.1 CommandManager

顶部的大标签栏会随文档类型变化：

- 零件：`特征`、`草图`、`评估`。
- 装配体：`装配体`、`布局`、`评估`。
- 工程图：`视图布局`、`注解`。

找不到命令时先确认：当前是否进入了草图、是否选中了正确对象、打开的是不是正确文档类型。

### 2.2 左侧管理器

- `FeatureManager`：设计树，显示基准面、草图、特征、配合和依赖顺序。
- `PropertyManager`：执行命令时输入方向、深度、角度等参数。
- `ConfigurationManager`：同一文件内管理不同尺寸或状态。
- `DisplayManager`：外观、贴图、布景和显示状态。

### 2.3 确认与取消

- 绿色对勾：接受当前命令。
- 红色叉：取消当前命令。
- `Esc`：退出当前工具或取消当前选择状态。
- 图形区右上角的确认角也可完成/取消草图和特征。

## 三、新建文档与模板

1. `Ctrl+N` 新建文档。
2. 选择 `零件`。
3. 右下角确认单位制，机械设计常用 `MMGS`：毫米、克、秒。
4. `文件 → 另存为`，立即保存到项目目录。

### 模板无效或单位总是不对

1. 新建零件并设置单位、制图标准、图像品质等。
2. `文件 → 另存为`，类型选 `Part Templates (*.prtdot)`。
3. 在 `工具 → 选项 → 系统选项 → 文件位置 → 文档模板` 中加入模板目录。
4. 重新新建文件，确认模板出现在“高级”页。

!!! warning "单位显示不是尺寸换算"
    把单位从 mm 改成 inch 会改变显示和输入解释。输入尺寸前始终看状态栏单位；也可以直接输入 `25.4mm` 或 `1in`，软件会自动换算。

## 四、选择对象

### 基本选择

- 单击：选择一个面、边、点、特征或零件。
- `Ctrl+单击`：增加/移除多个选择对象。
- 单击空白处或按 `Esc`：清除选择。
- 右键对象：显示与对象相关的快捷命令。

### 框选方向

- 从左向右框选：只选择完全落在框内的对象。
- 从右向左交叉框选：选择框内及被边界碰到的对象。

### 选择不到想要的面

右键当前位置，使用“选择其他”，轮换被遮挡的面；也可先临时隐藏挡住的零件或实体。

## 五、视图控制

| 操作 | 鼠标/键盘 | 用途 |
|---|---|---|
| 旋转模型 | 按住中键拖动 | 观察三维形状 |
| 缩放 | 滚轮 | 靠近或远离模型 |
| 平移 | `Ctrl` + 中键拖动 | 不改变观察方向地移动画面 |
| 正视于所选面 | `Ctrl+8` | 草图和检查平面最常用 |
| 等轴测 | `Ctrl+7` | 三维总览 |
| 整屏显示全部 | `F` | 找回跑出屏幕的模型 |
| 视图方向 | `Space` | 打开方向选择器 |
| 剖视图 | 视图工具栏 | 查看内部结构，不会切除实体 |

操作节奏：先选面 → `Ctrl+8` 正视 → 编辑草图；完成特征后 `Ctrl+7` 回等轴测。

## 六、保存、重建与撤销

- `Ctrl+S`：保存。首次保存先建立项目文件夹。
- `Ctrl+Z` / `Ctrl+Y`：撤销/重做。
- `Ctrl+B`：重建发生变化的特征。
- `Ctrl+Q`：强制从头完整重建，排错时使用，平时不必频繁按。

设计树出现交通灯或警告时，应先重建再查看最早出现错误的特征。

## 七、显示状态

- `Tab`：将鼠标指向的零件/实体隐藏。
- `Shift+Tab`：显示隐藏的零件/实体。
- 设计树右键对象可选择隐藏、透明、压缩或孤立。
- `压缩`不同于`隐藏`：隐藏只影响显示；压缩会停止计算该特征/零件。

## 八、推荐的首次设置

1. `工具 → 自定义 → 键盘`：查看或修改快捷键。
2. `工具 → 自定义 → 鼠标笔势`：设置 4 或 8 个高频命令。
3. 打开“动态高亮”，便于看清即将选择的面和边。
4. 关闭不需要的插件，缩短启动时间。
5. 设置自动恢复目录，但不要把自动恢复当作正常保存。

## 九、基础练习

- [ ] 新建 MMGS 零件模板并保存。
- [ ] 任意画一个长方体，练习旋转、缩放、平移、正视和等轴测。
- [ ] 隐藏/显示实体，区分隐藏与压缩。
- [ ] 修改尺寸后分别执行 `Ctrl+B` 和 `Ctrl+Q`。
- [ ] 自定义鼠标笔势并导出设置。
