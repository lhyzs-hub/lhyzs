# 科研绘图工具索引

>  这组笔记负责把数据处理、科研绘图和论文排版串成一条工作流。

## 工具笔记

- [Adobe Illustrator 2026 科研绘图零基础入门](adobe%20illustrator/[Adobe%20Illustrator%202026]%20科研绘图零基础入门.md)：机械原理与实验装置示意、CAD 底图标注、数据图拼版和论文导出。
- [Origin 2026 科研绘图小白实战教程](origin/[Origin%202026]%20科研绘图小白实战教程.md)：数据导入、作图、拟合、导出和科研图表整理。

## 推荐工作流

1. 在 Origin 中完成数据整理、统计和曲线绘制。
2. 以矢量格式导出图表，保留文字和线条的可编辑性。
3. 在 Adobe Illustrator 中统一字体、线宽、配色、图例和版式。
4. 按论文、汇报或投稿要求导出最终版本，并保留可编辑源文件。

## 维护提示

- 数据文件和中间产物放在对应工具的附件目录。
- 新增实验绘图案例时，回链到本页，并注明使用的工具和输出格式。
