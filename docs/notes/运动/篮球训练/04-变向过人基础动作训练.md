# 变向过人基础动作训练

返回：[00-篮球零基础到进阶路线图](00-篮球零基础到进阶路线图.md)　准备：[03-行进间运球、护球与弱手](03-行进间运球、护球与弱手.md)

## 过人的共同结构

有效变向不是“手快”而是五件事同时发生：

1. 用眼睛、肩、球或脚步给出一个方向的威胁。
2. 重心和髋部真实移位，让防守者必须反应。
3. 球快速穿过防守可触及区域。
4. 新方向第一步蹬地有力，肩髋越过防守者。
5. 过掉半个身位后把球放到远侧并切入防守路线。

## 六大基础变向

### 1. 体前变向（crossover）

- 接近防守前先减速；外侧脚踩地，髋与肩向假方向倾斜。
- 将球斜向推到另一只手，不要在身体正前方画大横线。
- 接球侧脚立即向新方向蹬出，换手后用身体护球。

### 2. 推球变向（push crossover）

- 球被主动“推”到新路线，身体同步跨出大步。
- 适合有横向空间时快速改线；不要让球先走、身体留在原地。

### 3. 胯下变向

- 前脚作为屏障，球从前脚后方穿过。
- 接球手提前放在路线末端；换手同时交换前后脚或跨步启动。
- 适合防守贴近、体前路线容易被切时。

### 4. 背后变向

- 髋向后坐，球从臀后斜推到另一侧。
- 身体先封住防守，球再通过；过点后不要继续横走。
- 适合保护球、改变推进线或避开正面抢断。

### 5. 转身运球

- 先用靠近防守的脚作内侧支点，肩背贴住路线而非用手推人。
- 球随身体在远侧髋旁完成换手，头先转向出口找空间。
- 转出后立即加速；不要原地转一圈仍面对同一位置。

### 6. 回撤/后拉运球

- 前脚刹车，髋向后坐，把球拉到后方安全区。
- 目的是脱离压力、重置角度，可衔接投篮、再突破或传球。
- 回撤后若防守继续扑上来，再做二次变向。

## 每个动作的四步练法

1. **无球影子步**：左右各 8 次，做到重心下降—蹬地—越过标志物。
2. **原地一运一换**：左右各 10 次，检查球的落点。
3. **标志碟变向**：每侧 5 次，出点后只运 2 下完成上篮。
4. **影子防守**：防守者只占路线、不抢球，进攻者读站位选择动作。

## 30 分钟基础课

- 热身与大力运球：5 分钟。
- 体前 + 胯下：各 3×5 次/侧。
- 背后 + 转身：各 3×5 次/侧。
- 回撤 + 二次启动：3×5 次/侧。
- “一次变向、两次运球内完成上篮”：每侧进 8 球。
- 3 次运球限制 1v1：6～10 回合。

## 如何选动作

| 防守情形 | 优先选择 |
|---|---|
| 防守离得远、横向空间大 | 体前或推球变向 |
| 防守贴近、手在球前 | 胯下或背后保护换向 |
| 防守过度压一侧 | 体前、背后或转身反向 |
| 路线被堵但尚未失去空间 | 回撤重置，再二次启动 |
| 防守身体已经越过你的前方 | 转身封住对方，球置远侧 |

## 常见无效动作

- 在防守两米外连续换手，却没有逼迫对方移动。
- 变向后仍横向走，没有向篮筐或空位加速。
- 只晃球不晃身体，肩、眼、髋都没有假动作。
- 固定背动作组合，不观察防守者的脚、髋和距离。
- 为追求幅度导致球离身体过远，或用托球制造停顿。

## 通关标准

- 六种动作左右方向各 5 次，能在 2 次后续运球内完成终结。
- 影子防守下 10 回合至少 7 次获得半个身位优势。
- 3 运球 1v1 中能主动使用“回撤重置”，而不是被逼停后乱传。
